# 🌤️ Weather App

A simple and responsive weather application built using React that allows users to search for weather conditions for any city in real time.

Check current weather information instantly through a clean and intuitive interface.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Display current temperature
- 💧 Humidity information
- 🌬️ Wind details
- ☁️ Weather conditions and icons
- ⚡ Real-time API data fetching
- 📱 Responsive design

## 🛠️ Technologies Used

- React
- JavaScript
- CSS
- Weather API
- Fetch API
